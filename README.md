# Pancreatic cancer research

Open computational research into pancreatic ductal adenocarcinoma (PDAC), using existing experimental datasets and reproducible methods. No clinical or therapeutic claims are made without appropriate validation.

See [programme](research/README.md), [research standards](AGENTS.md), [ethics](RESEARCH_ETHICS.md) and [licensing proposal](LICENSING.md). Initial priority: literature review and genetic dependency analysis; RNA inverse folding is a parallel exploratory methods track.

Status: foundation only; no original biological findings yet.
