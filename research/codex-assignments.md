## 1. Pancreatic organoid pharmacotyping, data audit and development-only reproduction

```text

Question: can Tiriac and colleagues’ published gemcitabine pharmacotranscriptomic score, frozen without using validation labels, be tested against independently measured single-agent gemcitabine sensitivity in pancreatic ductal adenocarcinoma organoids from Shi and colleagues? Establish feasibility, precision and reproducibility in the development cohort. Keep the held-out response values sealed. No therapeutic discovery, signature training, patient prediction or original held-out analysis in this assignment.

Read the source paper and supplements, not just the programme's estimates: Tiriac DOI 10.1158/2159-8290.CD-18-0349, Shi DOI 10.1038/s41467-022-29857-6 and GEO accession GSE194249. Check related reanalyses of both cohorts, particularly earlier gemcitabine signatures and later biobanks sharing centres/donors. Search exact score names, accessions, author groups and citations through the execution date. If another group has run this precise test, document the match and change the work's status to replication; never report novelty by default.

Start from the checked 39-to-38 histology/assay intersection, 66 measured development cultures, 123/130 initial exact symbol matches, and the existing hashed receipts under datasets. Recheck using an independent reader and focus new effort on the scoring reference and prior art. The paper identifies a few illustrative responses; disclose prior exposure and consider a prespecified sensitivity excluding exemplars. The 2 October 2026 HUGO Gene Nomenclature Committee table confirms that none of the seven absent genes can be recovered by an approved, previous or alias symbol in the external expression matrix. The exact 130-gene test is blocked with that input. First seek a permitted complete matrix for the same models and reproduce the original score in development data. Any 123-gene adaptation needs explicit owner approval and a separately locked estimand. Before accessing validation response values, freeze eligibility: confirmed malignant ductal histology, single-agent gemcitabine, comparable baseline expression, one independent observation per donor. Exclude normal samples, nonductal lesions and inseparable combinations. Prespecify how samples from multiple passages, sites or timepoints are chosen and retain a sensitivity analysis plan. Make a per-study provenance and data-rights manifest with file versions, URLs, checksums, model ID aliases, donor independence checks, assay duration, concentration grid, assessment time and readout. Store restricted data outside Git. The author cohorts use different assay durations: establish whether within-cohort ordering is a defensible endpoint. Support every proposed join with a source cross-reference. Preserve unresolved and unmatched counts. A separate process or reviewer may check presence, column schema and missingness of the held-out outcome while masking values; avoid printing labels.

Recover the exact original gene membership, direction, scoring and normalisation reference. In the versioned Supplementary Table S5 (DOI 10.1158/2159-8290.22533046.v1), the GEM profile has 225 scored rows, including 130 in the negative-correlation set used for the original sensitivity score. Confirm the methods-to-table mapping, not just the worksheet length. Verify which source publication, table and scoring variant you are reproducing. Record fixed per-gene parameters or a publisher-permitted prespecified transformation and how absent or duplicated genes are handled. If an original implementation requires jointly normalising discovery and validation data, distinguish literal reproduction from a legitimately portable adaptation, document the scientific difference and stop before substituting a new score without review. Do not choose a formulation based on validation performance.

In development data only, preregister one published numeric comparison or figure, exact sample set, scoring direction and an evidence-based tolerance for rounding. Reproduce it using source inputs, preserve failed controls and independently verify the sign, sample identifiers and result. Keep samples from the same donor together. Include a reversed-direction unit test, a deterministic shuffled-label null and a control for sorting/sign errors. Recovery of a training association after selecting correlated features is a code sanity check only. No drug-response ground truth is available from tumour expression alone.

Deliver a blinded attrition table and count independent eligible donors by study, known histology and exposure; no patient identifiers in Git. Prespecify a prospective primary estimand for later review: donor-level Spearman rank correlation between the fixed score and appropriately oriented external single-agent sensitivity, with a 95% interval and a donor-level permutation test. State how ties and missing outcomes are handled. Justify the smallest scientifically informative effect and attainable precision with simulations or exact calculations before unmasking. For protocol planning, require the owner to endorse that effect/precision objective rather than adopt an arbitrary sample-size threshold. Plan donor-outlier, growth-rate/proliferation and prior-treatment sensitivities if estimable. Assay duration and laboratory are perfectly confounded here; a separate duration effect would require additional matched data. Start statistical planning from datasets/precision.md. Secondary contrasts require multiplicity control; no subgroup search after seeing responses.

Use version-pinned dependencies and seeds, reproducible commands, data hashes and a clean independent rerun. Open a review pull request giving one of: feasible for later locked test / useful reproduction only / infeasible / prior art resolves proposed claim. Document missing rights, unavailable normalisation parameters, unresolved independence and scope. Do not advance into a held-out analysis from this assignment.
```

## 2. RNA inverse folding, paired replication using already published outputs

```text
Work in https://github.com/lukeroyle-beep/Pancreatic-cancer-research on a fresh research branch. Read current main, AGENTS.md, RESEARCH_ETHICS.md and licensing files. Read research/PCR-005/audit.md, assets.md and verify_archived_table.py from research/pcr-001-pcr-005-evidence-audit or its merged successor. Record exact commits. This is a methods replication confined to existing non-pathogenic synthetic benchmark records and public summary outputs. It does not require designing sequences, synthesising material, producing a therapeutic construct, or contacting the authors.

Reproduce the reported Turner success comparison in Boury, Bulteau and Ponty, DOI 10.4230/LIPIcs.WABI.2026.12, using the existing version 1.0.0 archive DOI 10.5281/zenodo.20266458. Read the specified alternative-fold set, target success definition, threshold for ties, parameter set and 5 kcal/mol search window. Distinguish the base-pair-distance endpoint in figure 15 of the 2025 paper DOI 10.1186/s13015-025-00278-6. The owner’s separate restricted stacking-only 0.93 kcal/mol proof is documented at public Bioinformatics commit 512777e4b72a412e80af1dc1f6ea40bb820e3522. It has already been rebuilt, and needs no rerun for this assignment.

Before inspecting outcome distributions, commit an analysis protocol specifying method labels, numerator, denominator, paired target-draw as the primary unit, exact treatment of ties, missingness, numerical tolerance and energy-window censoring. Inspect author definitions read-only. External code and results keep their own licences. Do not copy code or raw sequence-bearing files into the cancer repository. Run the existing archive integrity check on a temporary download. Expected metadata: 3,920 rows, 1,960 paired draws, 1,884 distinct dot-bracket targets and 49 parameter cells. Two columns called n must be checked independently. Report any discrepancy and stop on a hash mismatch.

Using a new table reader and a separately written verification path, report correct successes and denominators for each method, the paired contingency table and the signed percentage-point difference (Locked+ minus random). Compare against the paper's rounded 73% and 45% only once the protocol is locked. A toy table with a tie, failure, singleton and repeated target must expose an incorrect unpaired implementation or wrong sign. Preserve timeouts and ambiguous records. State which outcomes are published predictions, and which counts were recalculated. No claim of a proof under full Turner energies follows.

Estimate uncertainty conditional on the published synthetic sampling design. Inspect target and seed reuse across parameter cells and any dependence between both. Predefine an equal-weight-distinct-structure sensitivity result, a clustered confidence interval, and separate seed/parameter or multiway sensitivity when warranted. Keep the paired outputs together. Define the estimand if a structure appears several times with different algorithm draws. A simple unpaired row bootstrap is invalid. Any exploratory breakdown must use multiplicity adjustment and display its denominators. If the archive does not contain enough information for an ensemble quantity, report that boundary; do not infer ensemble occupancy from the minimum-energy gap.

Publish versioned scripts, environment, exact commands, hashes, read-only extraction provenance, independent verification receipt, limitations and negative outcomes in a review pull request. Separate successful reproduction, sensitivity to duplication, unresolved model-transfer questions and therapeutic relevance. Leave new therapeutic and biological work for a separate reviewed protocol.
```
